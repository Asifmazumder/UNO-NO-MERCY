# UNO Homies Online — Finished Multiplayer Build

## What is included
- 2–4 human players
- Private room codes
- Real-time WebSocket synchronization
- Separate phones/devices
- Mobile-first UI
- Lobby and host controls
- Wild color picker
- Draw / +2 / +4 / Skip / Reverse
- Rematch
- Reconnect-safe player presence
- No bots

## Run
Requires Node.js 18+.

```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Put it online
Deploy the whole folder to a Node.js host that supports WebSockets and HTTPS. After deployment, send the HTTPS game URL to your friends. They can open it on their phones and use the same room code.

For a public release, use original branding/assets rather than copying proprietary UNO branding or artwork.
